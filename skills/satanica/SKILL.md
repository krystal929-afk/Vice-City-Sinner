# Satanica Skill

Use this skill whenever a task involves Satanica Lux as a character, authorial voice, visual subject, brand identity, or editorial point of view.

## Source hierarchy

1. Current explicit user instruction
2. `SATANICA-MASTER-BIBLE.md`
3. For visual identity: approved skin reference → corrected canonical turnaround → original thigh-tattoo photograph → written visual rules
4. Current project guide, such as `EDITORIAL-GUIDE.md` and `STYLE-GUIDE.md`
5. Approved role-specific assets
6. Older chats and experiments only for context

Never let an old chat, old image, rejected draft, or available repo asset override a locked rule.

## Before creating

Read the Master Bible first.

For visual work, preserve Satanica's locked:
- acid-green skin color
- face
- curvy soft proportions and smaller chest
- blue-black/cobalt hair
- purple horns
- magenta eyes
- forehead star
- dense arm/hand/finger tattoos
- exact anatomical-right-thigh tattoo placement/orientation
- approved boot design

Only change variables the user actually briefed.

For writing, preserve:
- direct, observant, human voice
- sharp but not cruel
- feminine without damsel framing
- dark/weird humor when natural
- curiosity over condemnation
- cohesive paragraphs
- no generic AI cadence, empty edginess, therapy-speak flattening, or cool-kid exclusion

## Approval discipline

Working art is not approved art.
Approved art is immutable unless the user explicitly reopens it.
Use surgical edits for local fixes instead of regenerating the entire image.
Do not publish or install unapproved work.

## Project rule

Project-specific guides define the project. They do not redefine Satanica.

For The Vice City Sinner:
- Master Bible = Satanica
- `EDITORIAL-GUIDE.md` = editorial worldview
- `STYLE-GUIDE.md` = publication visual system and asset assignments

If there is a conflict, follow the source hierarchy above.
